# lcd-lab-LeeMendez-Cartmill
LCD display project for IoT lab
LCD lab reaction game
This code is to run a small game using one button, an lcd, an Arduino, several wires, and a 1K ressistor.
the game requires you to use a button to test your reaction speed, so that you can compete against others, your time will be displayed on the LCD screen.
